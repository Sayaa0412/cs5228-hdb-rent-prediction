# Supplementary experiment records

This folder is independent of the compiled report. It preserves the complete pre-existing experiment summary and saved metric index; no fitting or inference was rerun during the 3 November 2026 editorial revision.

- `CS5228_全部实验总结.md`: full project narrative, including failed directions and protocol differences.
- `saved_metrics_all_scopes.csv`: 1,018 saved metric rows from 28 source files; rows are not independent experiments.
- `four_window_results_by_source.csv`: matched-window results grouped by their source. A source/method record is not necessarily a unique fitted model.
- `final_C33_all_windows.csv`: final procedure on all evaluated windows.
- `final_component_comparison.csv`: final, prior and matched-component results.
- `low_rent_rule_metrics.csv`: rule-union diagnostic, separate from the earlier expert gate.
- `FEATURES_AND_SOURCES.md`: feature and historical-source definitions.
- `REPRODUCIBILITY.md`: entry points, dependencies, result index and remaining packaging limitation.
- `manifest.json`: original archive provenance, preserved unchanged. Its hashes refer to the original archived files, not this expanded folder.

Saved source identifiers are retained for traceability. Compare methods using their input information, chronological split and reference specification. Early protocols must not be merged into a single leaderboard. The report selects the evidence needed for its main argument; this archive retains the wider record. All evaluated windows have been exposed during development. No Kaggle score is asserted.
